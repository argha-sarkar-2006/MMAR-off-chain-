Deep Architectural Capabilities

No complex setup.
Preconfigured for multi-agent intelligence.

3rd-Route breaks the boundaries of conventional monolithic assistants. Instead of sending raw prompts to a single model, our intelligent router decomposes your problem and delegates each phase to specialized neural pipelines.

Every document you ingest becomes an instant, searchable extension of your agent's knowledge base without leaving your machine. 3rd-Route uses SQLite Full-Text Search (FTS5) with BM25 ranking to retrieve precise architectural specifications, code snippets, and research notes in sub-millisecond query cycles.
Learn more about Document Knowledge →
When your local documents do not have the answer, the Reasoning Stage triggers live web exploration through OpenRouter. It aggregates external API documentation, validates package versions, synthesizes key findings, and feeds verified context directly into the downstream code generator.
Explore the Reasoning Pipeline →
Upload system diagrams, UML charts, software UI screenshots, or raw error logs. The Vision Stage employs Tesseract OCR alongside Google Gemini Vision (with automatic fallback to OpenRouter vision models) to parse text, node relationships, and UI component hierarchies seamlessly.
View Vision & OCR Documentation →
You don't need to manually decide which model handles your query. modelrouter.py uses intelligent intent classification to inspect inputs and coordinate execution order: determining whether image analysis is required, whether RAG is relevant, and when code generation should be invoked.
Read how the Router works →
Produce working code directly from verified technical specifications. The Coding Stage hooks into Ollama Cloud models (such as gpt-oss:20b) or your self-hosted LLM endpoints to write clean, typed, modular code complete with unit tests and deployment instructions.

Privacy & Sovereignty First

Your workspace never leaves your device.

Unlike closed commercial cloud platforms that train models on your enterprise secrets and source code, 3rd-Route stores databases, vector contexts, chat logs, and ingested documents locally in self-contained SQLite containers.

  • Zero Cloud Telemetry — Chats and sessions run completely off-chain and offline-ready.
  • Isolated Workspaces — Auth0 authentication guarantees account-level knowledge partitioning.
  • Resilient Fallback — Automatic failover across Gemini and OpenRouter models prevents downtime.
Core Features

Engineered for Sovereign AI Engineers

Every component of 3rd-Route is built with modularity, performance, and developer freedom at its heart.

Account-Isolated Sessions

Integrated Auth0 authentication separates conversations and knowledge bases per user account, ensuring multi-tenant safety on shared machines.

Dynamic Multi-Engine Router

The router coordinates Vision, Reasoning, and Coding stages based on natural language intent or CLI flags without hardcoded lock-in.

SQLite FTS5 Knowledge Base

Native SQLite full-text search indexing provides instantaneous document chunking, BM25 ranking, and low-latency contextual recall.

Dual Web & CLI Workflows

Switch effortlessly between the sleek React desktop-inspired web UI and the headless command-line interface for automation scripts.

Automatic 503 Fallback

If the primary Gemini Vision provider experiences rate-limiting or outages, requests transparently cascade to backup OpenRouter vision models.

One-Click Release Packaging

Packaged as clean release archives (.zip, .tar.gz) on GitHub Releases. Extract, plug in your keys, and launch without external cloud setup.
